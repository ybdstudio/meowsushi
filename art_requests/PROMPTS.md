# Meow Hotpot Conveyor — art requests for ChatGPT

## Cách dùng
1. Mở **một** cuộc trò chuyện ChatGPT mới (bản có tạo ảnh). Dán đoạn **QUY TẮC CHUNG** bên dưới làm tin nhắn đầu tiên, kèm ảnh `references/00_style_anchor.png`.
2. Với mỗi việc từ 01 trở đi: gửi đúng ảnh trong `references/` có cùng số, cộng với prompt của việc đó. Mỗi tin nhắn chỉ làm một việc.
3. Tải ảnh ChatGPT trả về và đặt tên theo số việc (ví dụ `01_beef_counter.png`), rồi gửi lại cho Claude. Claude sẽ cắt, căn chỉnh và ghép vào game.
4. Nếu ChatGPT đổi góc nhìn, đổi số ô hoặc thêm nền, nhắn lại: *"Keep the exact same layout, angle and panel count as the reference, transparent background."*

Thứ tự ưu tiên (tác động lớn nhất trước): 01–06, rồi 11–13, rồi 07–10, rồi 16–17, cuối cùng 14–15.

---

## QUY TẮC CHUNG (dán một lần, kèm 00_style_anchor.png)

```
I'm reskinning my cozy mobile tycoon game "Meow Sushi Conveyor" into "Meow Hotpot Conveyor" (a hot pot conveyor restaurant, Chinese/Vietnamese style lẩu băng chuyền). The cat characters stay the same.

For every request I will attach an ORIGINAL game sprite (or a horizontal strip of several sprites). Please EDIT it, do not redraw from scratch:
- Keep exactly the same camera angle (isometric 3/4 view), object size, framing, proportions and position of every object inside each panel.
- Keep the same art style as the attached style anchor: chunky cute cartoon, thick dark-brown outline, soft cel shading, light from the top-left, saturated warm colors.
- Keep the same number of panels in the same order, same spacing, same total aspect ratio. Panels in a strip are animation frames or states of ONE object: they must stay consistent with each other (same counter, same cat, only the listed differences).
- Only replace the sushi-related items I describe. Everything else (wood, counters, metal, cats, furniture) stays as it is.
- Transparent background, PNG. No floor shadow, no text, no labels, no watermark.
```
